# ЗАДАНИЕ НА ДИПЛОМНЫЙ ПРОЕКТ

**Студент:** Ахмедьянов Саламат Ержанұлы

**Группа:** КПО 9/22-2

**Образовательная программа:** 06130100 «Программное обеспечение»

**Тема дипломного проекта:** «Разработка цифровой системы самопознания для анализа личностных предпочтений и направлений развития»

**Утверждена приказом №____ от «____» _____________ 2026 г.**

**Исходные данные к работе:**
Разработать прогрессивное веб-приложение (PWA) для анализа личностных предпочтений пользователя по 6 измерениям на основе интерактивных сценариев-дилемм. Приложение должно работать полностью в браузере без серверной части, поддерживать три языка (казахский, русский, английский) и визуализировать результаты с помощью радарных и столбчатых диаграмм.

**Содержание расчётно-пояснительной записки (перечень подлежащих разработке вопросов):**

1) Теоретические основы разработки системы самопознания: психология принятия решений, модели анализа личности, цифровые инструменты самопознания, визуализация данных, прогрессивные веб-приложения.

2) Проектирование системы: анализ требований, модель анализа по 6 измерениям, алгоритмы нормализации оценок, структура данных, архитектура приложения, проектирование интерфейса.

3) Реализация системы: выбор технологий, модуль сценариев и тестирования, модуль анализа личности, модуль визуализации, дополнительные модули.

4) Экспериментальная часть: методика тестирования, результаты тестирования, анализ полученных данных, ограничения и перспективы.

**Перечень графического материала:**
а) архитектура системы;
б) диаграммы классов;
в) блок-схемы алгоритмов;
г) скриншоты интерфейса;
д) примеры радарных диаграмм.
