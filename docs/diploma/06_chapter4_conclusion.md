## 4.1 Методика тестирования

Для оценки работоспособности и полезности разработанной системы были проведены три вида тестирования.

**Функциональное тестирование** направлено на проверку корректности работы всех модулей системы. Проверены следующие функции:

а) загрузка сценариев из JSON-файла и из встроенных данных (fallback);
б) корректность регистрации выборов и накопления оценок;
в) правильность нормализации по формулам (1)–(4);
г) корректность определения архетипа и категорий;
д) построение всех типов диаграмм (радарная, столбчатая, сравнительная);
е) сохранение и восстановление данных из localStorage;
ж) переключение языков (KK, RU, EN) и тем (светлая, тёмная);
з) экспорт отчёта в HTML;
и) работа в автономном режиме через Service Worker.

**Кроссбраузерное тестирование** проведено в следующих браузерах: Google Chrome 120, Mozilla Firefox 121, Microsoft Edge 120, Safari 17 (macOS). Во всех браузерах функциональность работала без ошибок. Были выявлены незначительные различия в отображении CSS-переходов в Safari, которые были устранены добавлением вендорных префиксов (-webkit-).

**Адаптивное тестирование** проведено на следующих размерах экрана:

а) мобильный телефон — 375×667 px (iPhone SE);
б) планшет — 768×1024 px (iPad);
в) ноутбук — 1366×768 px;
г) десктоп — 1920×1080 px.

Система корректно адаптируется ко всем размерам экранов. На мобильных устройствах боковое меню скрывается и вызывается кнопкой-гамбургером. Диаграммы автоматически масштабируются.

## 4.3 Анализ работы системы

**Производительность.** Замеры производительности показали следующие результаты:

а) время загрузки приложения (первый запуск) — 0.8 с;
б) время загрузки из кэша Service Worker — 0.2 с;
в) время анализа результатов (10 сценариев) — менее 5 мс;
г) время построения радарной диаграммы — менее 100 мс;
д) время переключения языка — менее 50 мс.

Все показатели существенно ниже пороговых значений Core Web Vitals [25], что свидетельствует о высокой производительности системы.

**Объём хранимых данных.** Средний объём данных одного прохождения в localStorage составляет ~2 КБ. При квоте localStorage в 5 МБ система способна хранить более 2500 результатов, что значительно превышает реалистичное число прохождений.

**Точность анализа.** Прямая верификация точности анализа затруднена ввиду отсутствия «золотого стандарта» для сравнения. Однако проведённый анализ внутренней согласованности показывает:

а) при повторном прохождении с теми же выборами результаты идентичны (детерминированность);

б) незначительные изменения в выборах приводят к пропорционально малым изменениям в результатах (устойчивость);

в) крайние стратегии (все выборы одного типа) дают ожидаемые крайние профили (валидность границ).

## 4.4 Ограничения и перспективы развития

**Текущие ограничения системы:**

а) **Ограниченный набор сценариев.** 10 базовых сценариев могут не покрывать всё разнообразие ситуаций принятия решений. При расширении набора может повыситься точность анализа.

б) **Экспертная оценка весов.** Веса вариантов определены экспертно, а не на основе факторного анализа эмпирических данных. Для повышения научной обоснованности необходима калибровка весов на большой выборке.

в) **Отсутствие нормативной базы.** Не проведена стандартизация результатов на репрезентативной выборке, что не позволяет сравнивать результат пользователя со среднестатистическим.

г) **Ограничения localStorage.** Данные хранятся только в одном браузере и могут быть утрачены при очистке данных браузера.

д) **Отсутствие валидации методики.** Необходимо исследование тест-ретестовой надёжности, конвергентной и дискриминантной валидности.

**Перспективы развития:**

а) расширение набора сценариев до 30–50 для повышения точности;
б) проведение эмпирического исследования для калибровки весов;
в) добавление серверного компонента (опционально) для синхронизации между устройствами;
г) разработка алгоритма адаптивного тестирования, подбирающего сценарии на основе предыдущих ответов;
д) интеграция с платформами профессиональной ориентации;
е) добавление элементов геймификации для повышения вовлечённости.

# ЗАКЛЮЧЕНИЕ

В ходе выполнения дипломного проекта была разработана цифровая система самопознания для анализа личностных предпочтений и определения направлений развития. Все поставленные задачи выполнены в полном объёме.

**По задаче 1** проведён анализ существующих подходов к анализу личности: рассмотрены модели Big Five, MBTI, DISC, теория самодетерминации, теория потока. Выявлены ограничения существующих подходов: дискретная типизация, влияние социальной желательности, серверная обработка данных. Обзор цифровых инструментов (16Personalities, Reflectly, StrengthsFinder) подтвердил отсутствие аналогов с сочетанием сценарного метода и полностью локальной обработки.

**По задаче 2** разработана модель анализа паттернов мышления по 6 измерениям: рациональность ↔ интуиция, контроль ↔ адаптация, стратегическое ↔ тактическое мышление, исследовательский потенциал ↔ исполнительность, индивидуализм ↔ коллективизм, поиск смысла ↔ утилитарность. Разработаны алгоритмы нормализации оценок (формулы 1–5) и система категоризации.

**По задаче 3** спроектирована модульная архитектура приложения на 4 уровнях (ядро, сервисы, бизнес-логика, представление), разработана структура данных JSON для 10 многоязычных сценариев с 4 вариантами выбора и системой весов.

**По задаче 4** реализованы модули тестирования (базовый, расширенный, когнитивный), анализа (PersonalityAnalyzer) и визуализации (ResultsVisualizer) с радарными, столбчатыми и сравнительными диаграммами. Общий объём кода — более 11000 строк на JavaScript, HTML и CSS.

**По задаче 5** созданы сравнительный анализ с профессиональными ролями, сравнение со знаменитыми личностями, система определения архетипа личности и экспорт HTML-отчёта.

**По задаче 6** реализована поддержка трёх языков (казахский, русский, английский) через модуль интернационализации i18n с JSON-файлами переводов.

**По задаче 7** проведено функциональное тестирование (15 тестовых сценариев — все пройдены), кроссбраузерное тестирование (4 браузера) и адаптивное тестирование (4 размера экрана). Все тесты пройдены успешно.

Практическая значимость работы заключается в создании бесплатного, конфиденциального и кроссплатформенного инструмента самопознания, который может быть использован в образовательных учреждениях для профессиональной ориентации учащихся, а также для личного самоанализа и осознанного планирования развития.

Система работает как прогрессивное веб-приложение, не требует установки, работает в автономном режиме и обеспечивает полную конфиденциальность данных за счёт локальной обработки.
