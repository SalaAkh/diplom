# Техническая архитектура и Структура кода

Этот документ описывает внутреннее устройство приложения **Self-Knowledge PWA**, архитектурные паттерны и взаимодействие модулей.

## 🏗 Архитектурный стиль: Local-First SPA

Приложение спроектировано как **Single Page Application (SPA)** на чистом JavaScript (Vanilla JS). Основная логика вынесена в сервисы и UI-контроллеры.

### Ключевые принципы

- **Zero Dependencies (в ядре):** Основная логика (анализ, хранение) не зависит от внешних библиотек.
- **Data-Driven UI:** Интерфейс строится на основе данных (JSON-сценарии, локали).
- **Event-Driven:** Модули взаимодействуют через события или прямые вызовы специализированных менеджеров.

## 🧠 Логика анализа (PersonalityAnalyzer)

Класс `PersonalityAnalyzer` выполняет следующие шаги:

1. **Сбор весов:** При выборе варианта ответа, веса (weights) из JSON добавляются к текущему вектору баллов.
2. **Нормализация:** Баллы делятся на количество вопросов и приводятся к диапазону `[-1, 1]`.
3. **Сопоставление (Mapping):** Нормализованный вектор сравнивается с эталонными архетипами и ролями с использованием Евклидова расстояния.

## 🎨 Дизайн-система (CSS)

В проекте используется кастомная CSS-архитектура, основанная на переменных (Design Tokens):

- **Цветовая схема:** Глубокие синие и фиолетовые оттенки с акцентами на градиенты.
- **Стекломорфизм (Glassmorphism):** Активное использование `backdrop-filter: blur()`, `rgba()` фонов и тонких границ.
- **Адаптивность:** Mobile-first подход с использованием Flexbox и CSS Grid.

## 🔧 Инструкции по разработке

1. **Добавление нового языка:**
   - Создайте JSON в `/locales/`.
   - Зарегистрируйте его в `i18n.js`.
   - Обновите селектор языков в UI.

2. **Добавление новых тестов:**
   - Отредактируйте `scenarios-data.js` (или соответствующий JSON).
   - Убедитесь, что сумма весов сбалансирована для всех осей.

3. **Сборка и Деплой:**
   - Проект статичен. Достаточно загрузить все файлы на GitHub Pages или любой Nginx сервер.
   - Убедитесь, что `sw.js` находится в корневом каталоге для правильной области видимости (Scope).
