# Руководство по развертыванию (Deployment Guide)

Это руководство описывает процесс деплоя приложения **Self-Knowledge PWA** на популярные платформы. Поскольку приложение является статическим (нет серверной части), процесс максимально упрощен.

## 1. Деплой на GitHub Pages (Рекомендуется)

Это самый простой и бесплатный способ хостинга для данного проекта.

### Шаги

1. Создайте новый репозиторий на GitHub.
2. Загрузите все файлы проекта в ветку `main`.
3. Перейдите в **Settings > Pages**.
4. В разделе "Build and deployment" выберите ветку `main` и папку `/ (root)`.
5. Нажмите **Save**. Через 1-2 минуты ваш сайт будет доступен по адресу `https://<username>.github.io/<repo-name>/`.

> [!IMPORTANT]
> При деплое на GitHub Pages в подпапку (не в корень домена), убедитесь, что пути в `manifest.json` и пути к Service Worker в `app.js` указаны корректно относительно корня репозитория.

---

## 2. Деплой на Vercel или Netlify

Эти платформы предоставляют автоматический CI/CD и поддержку HTTPS "из коробки".

### Шаги

1. Подключите ваш GitHub репозиторий к Vercel/Netlify.
2. Выберите проект.
3. Настройки сборки (Build Settings):
   - **Build Command:** Оставьте пустым (проект не требует сборки).
   - **Output Directory:** `.` (текущая папка).
4. Нажмите **Deploy**.

---

## 3. Локальный запуск для разработки

Для корректной работы Service Worker и PWA функций рекомендуется запускать проект через локальный сервер, а не просто открывать `index.html` как файл.

### С помощью VS Code (Live Server)

1. Установите расширение "Live Server".
2. Нажмите правой кнопкой на `index.html` -> **Open with Live Server**.

### С помощью Python

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

---

## 🔒 Настройка HTTPS

Для работы Service Worker и возможности установки приложения (PWA), сайт **обязательно** должен работать через протокол HTTPS (кроме `localhost`). GitHub Pages и Vercel предоставляют SSL-сертификаты автоматически.
