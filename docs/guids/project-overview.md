# Обзор проекта: Цифровая экосистема самопознания (Self-Knowledge PWA)

## 📌 О проекте (Дипломная работа)

Данный проект представляет собой современное **Progressive Web Application (PWA)**, разработанное в рамках **дипломной работы**. Приложение предназначено для глубокого психологического анализа и профориентации пользователей. В основе платформы лежит уникальная 6-мерная модель личности (6D-Model), которая позволяет выявлять скрытые паттерны поведения и профессиональные склонности через прохождение ситуационных сценариев (дилемм).

Приложение разработано с соблюдением принципов **Privacy by Design** — все данные хранятся и обрабатываются исключительно на стороне клиента в браузере (Local-First подход).

## 🚀 Ключевые архитектурные решения

1. **Vanilla Stack:** Проект написан на чистом HTML, CSS и JavaScript без использования тяжеловесных фреймворков (React/Vue/Angular). Это обеспечивает феноменальную скорость загрузки и молниеносный отклик интерфейса (TBT < 20мс) даже на слабых мобильных устройствах.
2. **Glassmorphism Design:** Визуальная стилистика построена на принципах неоморфизма и глассморфизма («стеклянный» UI), что создает премиальный, современный и визуально привлекательный пользовательский опыт.
3. **PWA & Offline-First:** Благодаря реализации Service Worker (`sw.js`) и стратегии кэширования *Stale-While-Revalidate*, приложение полностью автономно. Пользователь может проходить тесты и просматривать результаты без подключения к интернету.
4. **Многоязычность (i18n):** Нативная поддержка трех языков (русский, казахский, английский) с мгновенным переключением без перезагрузки страницы.

## ⚙️ Основной функционал

- **Сценарное тестирование:** Интерактивное прохождение тестов с плавными анимациями карточек.
- **Векторный анализ (Радарная диаграмма):** Построение 6-осевой диаграммы на базе результатов пользователя (с помощью `Chart.js` и 2D Canvas).
- **Match-Score:** Сравнение результатов пользователя с эталонными ролями (например, ИТ-архитектор, Менеджер продуктов).
- **Экспорт PDF/HTML:** Генерация визуально привлекательных отчетов с результатами для скачивания или печати.
- **Интеграция с Google Identity:** Опциональная OAuth авторизация.
- **Монетизация & CustDev:** Глобальная система донатов (BuyMeACoffee/Kaspi) для дипломного проекта и модуль обратной связи, работающий через бессерверную архитектуру (Formspree API).

## 💼 Для кого этот проект?

- **Целевая аудитория:** Школьники, студенты и профессионалы, стоящие перед выбором карьерного пути или желающие лучше понять свои сильные стороны.
- **Академическое значение:** Демонстрация навыков разработки современных веб-приложений без использования тяжелых фреймворков (Vanilla JS) и реализация сложных алгоритмов профилирования личности.

## 📂 Структура проекта (Core)

- `/js/services/` — Бизнес-логика, парсинг данных, монетизация.
- `/js/ui/` — Компоненты интерфейса (диаграммы, UI-анимации, графики).
- `/css/` — Мобильно-адаптивные стили, дизайн-токены ядра.
- `/docs/diploma/` — Академическая и техническая документация проекта.
- `/locales/` — JSON-файлы локализации.
