# История изменений (Changelog)

## Последнее обновление (Март 2026)

### Улучшения доступности (Accessibility)

- **Формы и поля ввода:** Добавлены атрибуты `autocomplete` для всех полей ввода, что упрощает и ускоряет их заполнение.
- **Связывание ярлыков:** Обеспечено наличие связанных тегов `<label>` для всех элементов форм. Это критически важно для корректной работы скринридеров и соответствия современным стандартам веб-доступности (WCAG).

### Пользовательский интерфейс и темы (UI/UX)

- **Дисплей и снижение нагрузки на зрение (Eye Strain Reduction):** Переработаны основные цвета светлой и темной тем оформления. Внесены корректировки для предотвращения излишнего контраста — темная тема теперь имеет более сбалансированные оттенки (не слишком темные), а светлая стала более мягкой (не слишком яркой). Это делает длительное использование системы более комфортным для глаз.

### Технические исправления

- **Оптимизация деплоя Firebase:** Обновлен конфигурационный файл `firebase.json`. В список исключений добавлен каталог `.git/**`, что позволило предотвратить загрузку сотен системных файлов репозитория при развертывании проекта в Firebase Hosting.
