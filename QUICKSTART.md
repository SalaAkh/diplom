## 🚀 Запуск проекта

1. Откройте файл `index.html` в современном браузере (Chrome, Firefox, Edge, Safari)
2. Система автоматически загрузится и отобразит вводный экран

## 📋 Что делать дальше

### Для пользователя:
1. Нажмите "Начать тестирование"
2. Прочитайте каждый сценарий и выберите вариант (A или B)
3. После прохождения всех 5 сценариев вы увидите результаты
4. Изучите свой профиль, графики и рекомендации
5. При необходимости скачайте результаты в формате JSON

### Для разработчика:

#### Добавление нового сценария:

Откройте `data/scenarios.json` и добавьте новый объект в массив `scenarios`:

```json
{
  "id": 6,
  "title": "Ваш сценарий",
  "description": "Описание дилеммы",
  "optionA": {
    "text": "Вариант A",
    "weights": {
      "systematic": 0.5,
      "peopleOriented": -0.3,
      "riskTolerance": 0.2,
      "strategic": 0.4,
      "exploration": -0.1
    }
  },
  "optionB": {
    "text": "Вариант B",
    "weights": {
      "systematic": -0.4,
      "peopleOriented": 0.6,
      "riskTolerance": -0.3,
      "strategic": -0.2,
      "exploration": 0.5
    }
  }
}
```

**Важно**: Веса должны быть в диапазоне от -1.0 до +1.0

#### Изменение стилей:

Отредактируйте `css/styles.css`. Основные переменные определены в `:root`:

```css
:root {
    --primary-color: #4a90e2;
    --secondary-color: #7b68ee;
    /* ... */
}
```

#### Изменение логики анализа:

Отредактируйте методы в `js/analysis.js`:
- `generateSummary()` - для изменения общего резюме
- `generateRecommendations()` - для изменения рекомендаций

## 🔧 Решение проблем

### Графики не отображаются
- Проверьте подключение к интернету (Chart.js загружается через CDN)
- Или установите Chart.js локально

### Данные не загружаются
- Убедитесь, что файл `data/scenarios.json` существует
- Проверьте консоль браузера на наличие ошибок
- Убедитесь, что вы открываете через HTTP-сервер (не file://)

### Результаты не сохраняются
- Проверьте, что localStorage доступен в браузере
- Очистите кэш браузера и попробуйте снова

## 📝 Запуск через локальный сервер (рекомендуется)

Для корректной работы с JSON файлами рекомендуется использовать локальный сервер:

### Python:
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

### Node.js (http-server):
```bash
npx http-server -p 8000
```

### PHP:
```bash
php -S localhost:8000
```

Затем откройте в браузере: `http://localhost:8000`

## 🎨 Кастомизация

### Изменение цветовой схемы:

В `css/styles.css` измените переменные:

```css
:root {
    --primary-color: #ваш_цвет;
    --secondary-color: #ваш_цвет;
}
```

### Добавление новых измерений:

1. Добавьте в `data/scenarios.json` → `dimensions`
2. Добавьте веса в каждый сценарий
3. Обновите методы анализа в `js/analysis.js`

Результаты сохраняются в формате:

```json
    ...
  },
  "statistics": {
    "totalChoices": 5,
    "totalScenarios": 5,
    "completionRate": 100
  }
}
```
