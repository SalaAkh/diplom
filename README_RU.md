## 📋 Описание проекта

Данный дипломный проект представляет собой цифровую систему для анализа личностных предпочтений и направлений развития пользователя через интерактивные сценарии выбора. Система написана на HTML, CSS и JavaScript, работает полностью в браузере без использования сервера (serverless).

### Основные возможности

- **Интерактивные сценарии** — 12 дилемм с 3–4 вариантами выбора
- **Когнитивный тест** — определение когнитивного стиля по 6 измерениям
- **Расширенный тест** — углубленные сценарии дилемм
- **Динамическая логика** — адаптивный выбор следующих вопросов на основе предыдущих ответов
- **Анализ паттернов** — автоматический анализ выборов пользователя по 6 измерениям
- **Эволюция профиля** — отслеживание изменений результатов между сессиями
- **Сравнение с известными личностями** — сопоставление профиля с известными людьми
- **Визуализация результатов** — отображение профиля личности через диаграммы и графики
- **Локализация** — поддержка казахского, русского и английского языков (KK / RU / EN)
- **Доступность** — контрастность, размер шрифта, звуковая обратная связь, чтение вслух (Text-to-Speech)
- **Локальная обработка** — все данные хранятся в браузере, отсутствие сервера

## 🎯 Цель проекта

Создание интерактивной системы, служащей инструментом для самопознания пользователей:

- Определение личных предпочтений в принятии решений
- Исследование паттернов мышления
- Предоставление конкретных рекомендаций по направлениям развития
- Визуализация профиля личности

## 🔬 Модель анализа — 6 измерений

| # | Измерение | Описание |
|---|---|---|
| 1 | **Стратегическое мышление** | Долгосрочное планирование и системное мышление |
| 2 | **Исследователь** | Открытость новому опыту, стремление изучать неизведанное |
| 3 | **Индивидуализм** | Баланс между независимостью и коллективным мышлением |
| 4 | **Рациональность** | Приоритет логики и анализа при принятии решений |
| 5 | **Контроль** | Стремление управлять ситуацией |
| 6 | **Поиск смысла** | Поиск глубокого смысла в действиях и событиях |

## 🚀 Запуск проекта

1. Клонируйте или скачайте проект.
2. Откройте `index.html` в современном браузере.
3. Начните тест.

**Требования:**

- Современный браузер с поддержкой ES6+ (Chrome, Firefox, Edge, Safari)
- Интернет-соединение (для загрузки Chart.js из CDN)

> **Примечание:** Основной источник данных — `js/data/scenarios-data.js`. Файл `data/scenarios.json` используется как резервный вариант при запуске через веб-сервер.

## ⚙️ Доступность (Accessibility)

- **Режим высокой контрастности** — для пользователей с нарушениями зрения
- **Регулировка размера текста** — 4 уровня (маленький, обычный, крупный, очень крупный)
- **Звуковая обратная связь** — звуковое подтверждение действий
- **Чтение результатов вслух** — использование синтеза речи (TTS)
- **Клавиатурная навигация** — полная навигация без мыши
- **ARIA атрибуты** — полная совместимость с экранными дикторами (Screen Readers)
- **Доступность форм** — атрибуты `autocomplete` и связанные теги `<label>` для всех полей ввода
- **Снижение нагрузки на зрение** — оптимизированный цветовой баланс для светлой и темной тем

Полное руководство: [ACCESSIBILITY.md](ACCESSIBILITY.md)

## 📊 Структура данных сценария

Каждый сценарий в `scenarios-data.js`:

```js
{
  id: 1,
  title: "Название дилеммы",
  description: "Описание ситуации",
  options: [
    {
      text: "Текст варианта A",
      weights: {
        strategic: 0.7,      // Стратегическое мышление
        explorer: -0.4,      // Исследователь
        rationality: 0.3,    // Рациональность
        individualism: 0.5,  // Индивидуализм
        control: -0.2,       // Контроль
        meaning: 0.6         // Поиск смысла
      }
    },
    // ...
  ]
}
```

**Веса** (`weights`) — определяют влияние выбора на каждое измерение:

- Диапазон: от `-1.0` до `+1.0`
- Положительное значение — увеличивает склонность к измерению
- Отрицательное значение — уменьшает

## 🎓 Для защиты диплома

### Научная новизна

- Сочетание 6 независимых измерений в одной модели
- Количественный анализ выборов через весовые коэффициенты
- Интерактивный подход через сценарные дилеммы
- Система отслеживания эволюции профиля

### Практическая значимость

- Работающая веб-система (без сервера)
- Приватная обработка данных (локально)
- Поддержка 3 языков
- Полная доступность (стандарты WCAG)

### Ожидаемые вопросы на защите

**Почему именно эти 6 измерений?**  
→ Комплексный подход, охватывающий ключевые аспекты принятия решений.

**Как определены веса в сценариях?**  
→ Основаны на теоретических моделях; могут быть уточнены через эмпирические исследования.

**Валидность результатов?**  
→ Система предназначена для самопознания, а не для клинической диагностики. Результаты носят рекомендательный характер.

**Почему локальная обработка?**  
→ Конфиденциальность данных пользователя, независимость от серверной инфраструктуры.
