# Документация по функциям доступности (Accessibility)

Данный проект спроектирован с учетом стандартов WCAG 2.1 и предоставляет широкие возможности для пользователей с ограниченными возможностями (зрение, моторика, когнитивные особенности).

## 1. Горячие клавиши (Keyboard Navigation)

Система поддерживает полную навигацию без использования мыши:

* `Tab` / `Shift + Tab` — Перемещение между интерактивными элементами.
* `Enter` / `Space` — Активация кнопок и ссылок.
* `Alt + A` — Открыть/закрыть меню настроек доступности.
* `Alt + S` — Быстрый запуск тестирования (со страницы выбора).
* `Esc` — Закрытие модальных окон.

## 2. Настройки доступности

Меню настроек доступности (`кнопка с иконкой "человечка"` в шапке сайта) позволяет настроить интерфейс под индивидуальные нужды:

### Контрастность

* **Обычная:** Стандартная цветовая схема.
* **Высокая:** Черно-желто-белая схема для максимальной читаемости. Соответствует стандарту WCAG AAA (соотношение контрастности > 7:1).

### Размер текста

* Доступны 4 уровня: Мелкий, Обычный, Крупный, Очень крупный (до 200%).
* Весь интерфейс построен на относительных единицах измерения (`rem`), что предотвращает "расползание" при масштабировании.

### Анимации интерфейса

* Позволяет отключить все фоновые анимации, параллакс-эффекты и переходы. Рекомендуется для пользователей с вестибулярными нарушениями или эпилепсией.

### Звуковое сопровождение

* Включает звуковые сигналы (аудио-дескрипцию действий) при навигации, смене темы, успешном сохранении и ошибках.

### Упрощенный режим

* Скрывает все сложные визуальные элементы (3D частицы, фоновые планеты, градиенты).
* Упрощает структуру карточек, убирая тени и сложные обводки.
* Максимально фокусирует внимание на текстовом контенте.

### Озвучивание результатов (TTS)

* Использует технологию синтеза речи (Web Speech API) для автоматического прочтения итогового профиля личности и рекомендаций.

## 3. Поддержка Screen Reader (Программ чтения экрана)

* **Семантическая разметка:** Используются теги `main`, `nav`, `section`, `article`, `header`, `footer`.
* **ARIA-метки:** Все иконки (Material Symbols) снабжены скрытыми описаниями `aria-label`. Динамические сообщения (например, "Тест загружается") используют `aria-live` регионы.
* **Визуализации:** 3D-модели и 2D-графики сопровождаются детализированными текстовыми описаниями, которые автоматически формируются при генерации результатов.

## 4. Рекомендации по использованию

Для наилучшего опыта использования с экранными дикторами (NVDA, JAWS, VoiceOver) рекомендуется:

1. Активировать **Упрощенный режим** для минимизации лишних элементов в DOM.
2. Использовать **Озвучивание результатов**, если нужно получить быстрый аудио-отчет.
3. Пользоваться горячими клавишами для быстрой навигации.
