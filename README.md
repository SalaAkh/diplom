# Система самопознания: Анализ личностных предпочтений

**Автор:** Ахмедьянов Саламат КПО 9/22-2  
**Дата:** 2026  
**Учебное заведение:** Колледж Инновационных Технологий КарТУ имени Абылююкаса Сагинова

## 📋 Описание проекта

Учебно-исследовательский дипломный проект, представляющий собой цифровую систему для анализа личностных предпочтений и направлений развития пользователя через интерактивные сценарии выбора.

### Основные возможности

- **Интерактивные сценарии**: 12 дилемм с 3-4 вариантами выбора каждая
- **Динамическая логика**: Адаптивный выбор следующих вопросов на основе предыдущих ответов
- **Анализ паттернов**: Автоматический анализ выборов пользователя по 6 измерениям
- **Векторная модель мышления**: Каждый пользователь представлен как набор числовых векторов
- **Улучшенный AI-анализ**: Глубокий анализ последовательности выборов, обнаружение противоречий, выявление паттернов решений
- **Визуализация результатов**: Множественные графики и диаграммы профиля личности
- **Категоризированные рекомендации**: 6 категорий направлений развития с детальными рекомендациями
- **Векторы развития**: Определение комбинаций измерений (например, "Исследователь-Стратег")
- **Рекомендации по навыкам**: Конкретные навыки для развития на основе профиля
- **Эволюция профиля**: Отслеживание изменений результатов между сессиями
- **Локальная работа**: Все данные обрабатываются в браузере, без отправки на сервер

## 🎯 Цель проекта

Разработать инструмент для самопознания, который помогает пользователям:

- Понять свои предпочтения в принятии решений
- Выявить паттерны мышления
- Получить рекомендации по направлениям развития
- Визуализировать свой личностный профиль

## 🔬 Модель анализа

Система анализирует пользователя по 5 измерениям:

1. **Системное ↔ Интуитивное мышление**
   - Склонность к структурированному, логическому анализу vs интуитивному подходу

2. **Ориентация на людей ↔ Процессы**
   - Фокус на межличностных отношениях vs структурах и процессах

3. **Склонность к риску**
   - Готовность принимать неопределённость и рисковать

4. **Стратегическое ↔ Тактическое мышление**
   - Фокус на долгосрочных целях vs краткосрочных результатах

5. **Потребность в исследовании**
   - Стремление к новым знаниям и глубокому пониманию

## 📊 Структура данных сценариев

Каждый сценарий в `scenarios.json` содержит:

```json
{
  "id": 1,
  "title": "Название дилеммы",
  "description": "Описание ситуации",
  "optionA": {
    "text": "Текст варианта A",
    "weights": {
      "systematic": 0.7,
      "peopleOriented": -0.4,
      "riskTolerance": -0.8,
      "strategic": 0.3,
      "exploration": 0.5
    }
  },
  "optionB": {
    "text": "Текст варианта B",
    "weights": { /* веса для измерения */ }
  }
}
```

**Веса** (`weights`) определяют влияние выбора на каждое измерение:

- Диапазон: от -1.0 до +1.0
- Положительные значения увеличивают склонность к измерению
- Отрицательные значения уменьшают склонность (увеличивают противоположное измерение)
- Каждый вариант может влиять на несколько измерений с разными весами

**Динамическая логика выбора сценариев**:

- Первые 4 сценария показываются в фиксированном порядке
- Последующие сценарии выбираются адаптивно на основе:
  - Выявленных тенденций пользователя
  - Противоречий в выборах
  - Баланса измерений профиля
- Отрицательные значения уменьшают склонность

## 📝 Примеры сценариев

Проект включает 10 сценариев:

1. **Стабильность или Свобода** - выбор между гарантированной работой и предпринимательством
2. **Знания или Власть** - выбор между экспертизой и руководящей позицией
3. **Индивидуальное или Коллективное** - выбор между самостоятельной и командной работой
4. **Проверенный путь или Новое направление** - выбор между традиционным и инновационным подходом
5. **Долгосрочная стратегия или Быстрый результат** - выбор временного горизонта
6. **Творчество или Репродукция** - выбор между созданием нового и использованием готовых решений
7. **Конкуренция или Сотрудничество** - выбор между соревновательным и кооперативным подходом
8. **Детали или Общая картина** - выбор между фокусом на деталях и видением целого
9. **Традиции или Инновации** - выбор между проверенными методами и новыми подходами
10. **Автономия или Интеграция** - выбор между независимостью и включённостью в систему
