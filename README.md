# Өзін-өзі тану жүйесі — Жеке қалауларды талдау

**Автор:** Ахмедьянов Саламат, КПО 9/22-2  
**Жыл:** 2026  
**Оқу орны:** Абылқас Сағынов атындағы Қарағанды Техникалық Университетінің Инновациялық Технологиялар Колледжі

---

## 📋 Жоба сипаттамасы

Бұл дипломдық жоба — интерактивті таңдау сценарийлері арқылы пайдаланушының жеке қалаулары мен даму бағыттарын талдайтын цифрлық жүйе. Жүйе HTML, CSS және JavaScript тілдерінде жазылған, серверсіз, толығымен браузер жағында жұмыс істейді.

### Негізгі мүмкіндіктер

- **Интерактивті сценарийлер** — 3–4 таңдау нұсқасы бар 12 дилемма
- **Когнитивті тест** — 6 өлшем бойынша когнитивті стильді анықтау
- **Кеңейтілген тест** — тереңдетілген дилемма сценарийлері
- **Динамикалық логика** — алдыңғы жауаптарға негізделген бейімделгіш сценарий таңдауы
- **Паттерн талдауы** — 6 өлшем бойынша пайдаланушы таңдауларын автоматты талдау
- **Профиль эволюциясы** — сессиялар арасындағы нәтижелер өзгерістерін бақылау
- **Атақты тұлғалармен салыстыру** — профильді белгілі тұлғалармен салыстыру
- **Нәтижелерді визуализациялау** — диаграммалар мен кестелер арқылы тұлға профилін бейнелеу
- **Локализация** — қазақ, орыс, ағылшын тілдерін қолдау (KK / RU / EN)
- **Қолжетімділік** — контраст, мәтін өлшемі, дыбыстық кері байланыс, дауыстап оқу
- **Жергілікті өңдеу** — барлық деректер браузерде сақталады, сервер жоқ

---

## 🎯 Жоба мақсаты

Пайдаланушыларға өз-өзін тануға қызмет ететін интерактивті жүйені жасау:

- Шешімдер қабылдаудағы жеке қалауларды анықтау
- Ойлау паттерндерін зерттеу
- Даму бағыттары бойынша нақты ұсыныстар беру
- Тұлға профилін визуализациялау

## 🔬 Талдау моделі — 6 өлшем

| # | Өлшем | Сипаттама |
|---|---|---|
| 1 | **Стратегиялық ойлау** | Ұзақ мерзімді жоспарлау мен жүйелі ойлау |
| 2 | **Зерттеуші** | Жаңа тәжірибеге ашықтық, белгісізді зерттеуге құштарлық |
| 3 | **Жекешілдік** | Тәуелсіздік пен ұжымдық ойлау балансы |
| 4 | **Рационалдық** | Шешімдерде логика мен талдауға басымдық |
| 5 | **Бақылау** | Жағдайды басқаруға ұмтылу |
| 6 | **Мағына іздеу** | Іс-әрекеттерден терең мән іздеу |

## 🚀 Жобаны іске қосу

1. Жобаны клондаңыз немесе жүктеп алыңыз
2. `index.html` файлын заманауи браузерде ашыңыз
3. Тестті бастаңыз

**Талаптар:**

- ES6+ қолдайтын заманауи браузер (Chrome, Firefox, Edge, Safari)
- Интернет байланысы (Chart.js CDN-ден жүктеу үшін)

> **Ескерту:** Деректердің негізгі көзі — `js/data/scenarios-data.js`. `data/scenarios.json` файлы веб-сервер арқылы іске қосу кезінде резервтік нұсқа ретінде пайдаланылады.

## ⚙️ Қолжетімділік (Accessibility)

- **Жоғары контраст режимі** — көру қабілеті бұзылған пайдаланушылар үшін
- **Мәтін өлшемін реттеу** — 4 деңгей (кіші, қалыпты, үлкен, өте үлкен)
- **Дыбыстық кері байланыс** — іс-әрекеттерді дыбыстық растау
- **Нәтижелерді дауыстап оқу** — сөйлеу синтезі арқылы
- **Пернетақта навигациясы** — тышқансыз толық навигация
- **ARIA атрибуттары** — экран оқушыларымен толық үйлесімділік
- **Автотолтыру және форма қолжетімділігі** — барлық форма өрістері үшін autocomplete атрибуттары мен label тегтері
- **Көздің шаршауын азайту** — ашық және қараңғы тақырыптардың түс балансы оңтайландырылған

Толық нұсқаулық: [ACCESSIBILITY.md](ACCESSIBILITY.md)

## 📊 Сценарий деректерінің құрылымы

`scenarios-data.js` ішіндегі әр сценарий:

```js
{
  id: 1,
  title: "Дилемма атауы",
  description: "Жағдай сипаттамасы",
  options: [
    {
      text: "A нұсқасының мәтіні",
      weights: {
        strategic: 0.7,
        explorer: -0.4,
        rationality: 0.3,
        individualism: 0.5,
        control: -0.2,
        meaning: 0.6
      }
    },
    // ...
  ]
}
```

**Салмақтар** (`weights`) — таңдаудың әр өлшемге ықпалын анықтайды:

- Диапазон: `-1.0` ден `+1.0` дейін
- Оң мән — өлшем бойынша бейімділікті арттырады
- Теріс мән — азайтады

## 🎓 Диплом қорғауы үшін

### Ғылыми жаңалық

- 6 тәуелсіз өлшемнің бір модельде үйлесуі
- Салмақтық коэффициенттер арқылы таңдаудың сандық талдауы
- Дилемма сценарийлері арқылы интерактивті тәсіл
- Профиль эволюциясын бақылау жүйесі

### Практикалық маңызы

- Жұмыс істейтін веб-жүйе (серверсіз)
- Деректердің жеке өңделуі (приватность)
- 3 тілді қолдау
- Толық қолжетімділік (WCAG стандарттары)

### Қорғауда күтілетін сұрақтар

**Неліктен дәл осы 6 өлшем?**  
→ Шешімдер қабылдаудың негізгі аспектілерін қамтитын кешенді тәсіл.

**Сценарийлердегі салмақтар қалай анықталды?**  
→ Теориялық модельдерге негізделген; эмпирикалық зерттеулер арқылы нақтылауға болады.

**Нәтижелердің негізділігі?**  
→ Жүйе өзін-өзі тануға арналған; клиникалық диагностика емес. Нәтижелер ұсыным сипатында.

**Неліктен жергілікті өңдеу?**  
→ Пайдаланушы деректерінің құпиялылығы, сервер инфрақұрылымына тәуелсіздік.
