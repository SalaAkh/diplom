### 2.2. Модель анализа личностных предпочтений

#### 2.2.1. Выбор измерений
**5 измерений:**
1. Системное ↔ Интуитивное мышление
2. Ориентация на людей ↔ Процессы
3. Склонность к риску
4. Стратегическое ↔ Тактическое мышление
5. Потребность в исследовании

**Обоснование выбора:**
- Покрытие ключевых аспектов принятия решений
- Независимость измерений
- Измеримость через выборы в дилеммах

#### 2.2.2. Алгоритм нормализации
```
Для каждого измерения:
  score = сумма весов всех выборов
  normalizedScore = score / количество выборов
  normalizedScore = ограничить в диапазоне [-1, 1]
```

**Формула:**
```
normalizedScore[d] = clamp(sum(weights[d]) / N, -1, 1)
где:
  d - измерение
  weights[d] - веса выбора по измерению d
  N - количество выборов
  clamp(x, min, max) - ограничение значения
```

#### 2.2.3. Формула вычисления профиля
- Процентные значения: `percentage = normalizedScore * 100`
- Уровни склонности на основе пороговых значений
- Генерация текстовых описаний
