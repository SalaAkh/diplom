# Оптимизация библиотек проекта

## Выполненные изменения (31.01.2026)

### 🔄 Миграция на CDN

Все крупные JavaScript библиотеки были перенесены на CDN для оптимизации:

#### 1. **html2pdf.js** (~1 МБ)

- **Было:** `js/lib/html2pdf.bundle.min.js`
- **Стало:** CDN от cdnjs.cloudflare.com
- **Версия:** 0.10.1
- **Файлы:** `index.html`, `profile.html`

#### 2. **Chart.js** (~200 КБ)

- **Было:** `js/lib/chart.umd.min.js`
- **Стало:** CDN от cdn.jsdelivr.net
- **Версия:** 4.4.1
- **Файлы:** `index.html`, `profile.html`

#### 3. **Three.js** (уже был на CDN)

- **Источник:** cdnjs.cloudflare.com
- **Версия:** r128

### ✅ Преимущества

1. **Уменьшение размера репозитория** - удалено ~1.2 МБ файлов
2. **Улучшенная производительность** - браузерное кэширование CDN
3. **Безопасность** - SRI (Subresource Integrity) проверки
4. **Актуальность** - легкое обновление версий
5. **Надежность** - резервные копии на CDN серверах

### 📋 Удаленные файлы

```text
js/lib/html2pdf.bundle.min.js          (~1 МБ)
js/lib/html2pdf.bundle.min.js.LICENSE.txt
js/lib/chart.umd.js.map                (~950 КБ)
patch_html2pdf.js
patch_html2pdf_v2.js
```

### 🔒 Безопасность

Все CDN скрипты включают:

- `integrity` - проверка целостности файла
- `crossorigin="anonymous"` - CORS политика
- `referrerpolicy="no-referrer"` - защита приватности

### 📝 .gitignore

Создан файл `.gitignore` для исключения:

- `node_modules/`
- `*.map` (source maps)
- IDE файлов
- Временных файлов
- Логов

### 🚀 Рекомендации

Для офлайн работы браузер автоматически кэширует CDN файлы после первой загрузки.

Если требуется полностью автономная версия, можно:

1. Скачать библиотеки вручную
2. Использовать Service Worker для кэширования
3. Настроить локальный сервер
